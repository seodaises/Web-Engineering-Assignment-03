## ✨ Features

- ✅ SPA routing with dynamic routes (`/view/:id`, `/edit/:id`)
- ✅ Full CRUD operations on Firestore
- ✅ Real-time data sync with `onSnapshot`
- ✅ Light/Dark mode toggle
- ✅ Responsive design
- ✅ Form validation
- ✅ Loading and error states


## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/seodaisies/Web-Engineering-Assignment-03.git
cd roomsync-profiles

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
